Mosafer — Smart Travel Management Platform Architecture

معمارية نظام مسافر (محدّثة وفق الكود الفعلي)

Presentation Tier

Mobile App (Flutter)

  • Clean Architecture
  • Presentation: UI / Widgets
  • Riverpod + GoRouter
  • مسح QR / رفع التذكرة / رحلاتي
  • API Communication (Dio / HTTP)

Web App (Next.js)

  • App Router + next-intl (ar/en)
  • حجز الرحلات + الدفع + التأكيد
  • لوحة إدارة (Admin Dashboard)
  • BFF Routes → FastAPI (cookies)
  • API Communication (HTTP)

Backend API (FastAPI)

  • REST Controllers (Routers)
  • /api/v1 (+ /api/v2 health)
  • JWT Auth + RBAC Permissions
  • Request / Response Schemas
  • Middleware: CORS, Rate Limit, Security
⇅ ⇅ ⇅
Business Tier

Mobile App (Flutter)

  • Domain Layer + Use Cases
  • إدارة الرحلة النشطة والمراحل
  • Claim التذكرة للمستفيدين
  • Controllers (Riverpod Notifiers)
  • State & Validation

Web App (Next.js)

  • Checkout / Passengers / Payment Return
  • خدمات الحجز لكل ميزة
  • تحليلات الإدارة (Revenue / Profit)
  • قواعد التحقق من النماذج
  • Session عبر httpOnly cookies

Backend (FastAPI)

  • Services Layer (Business Rules)
  • Booking / Tickets / Reservations
  • NotificationDispatcher
  • PaymentService (Mock أو Stripe)
  • AI Travel Agent (OpenAI)
⇅ ⇅ ⇅
Data Tier

Mobile App (Flutter)

  • Repositories (Data Layer)
  • ApiClient + Interceptors
  • FlutterSecureStorage (JWT)
  • SharedPreferences (locale/theme)
  • تخزين محلي للرحلات المحذوفة

Web App (Next.js)

  • API Routes كطبقة وصول
  • تكامل مع FastAPI لكل ميزة
  • Cookies: access_token / refresh_token
  • لا يوجد DB مباشر في الويب
  • Server + Client Components

Backend (FastAPI)

  • SQLAlchemy Models (async)
  • Alembic Migrations
  • Pydantic Schemas
  • PostgreSQL Repositories
  • Redis Cache + Dedup Keys

PostgreSQL Database

  • Primary Data Storage
  • Users / Tickets / Reservations
  • Payments / Notifications
  • Booking Passengers / Devices

External Services & Integrations

  • Mock Payment (افتراضي) — التطوير والاختبار
  • Stripe (اختياري) — عند PAYMENT_PROVIDER=stripe
  • Firebase FCM — Push للموبايل
  • SMTP Email — Mailpit (dev) / Gmail (prod)
  • OpenAI API — نصائح السفر والـ AI Agent
  • Google Maps / Routes — خرائط ومسارات
  • Mock Flight / Weather / Maps — بيانات تطوير
  • Redis + ARQ Workers — مهام خلفية وإشعارات
تصحيحات عن الصورة الأصلية: الدفع ليس Stripe دائماً — النظام يستخدم Mock Payment افتراضياً وStripe فقط عند التفعيل. البريد عبر SMTP وليس Resend. أُضيف Redis + ARQ Workers وNext.js كويب فعلي. الحجز والدفع من الويب؛ الموبايل يركز على إدارة الرحلة بعد الحجز.
